# Online Bookstore SQL Project

## Project Overview
This project focuses on managing an online bookstore database using MySQL. It includes books, customers, and orders data to practise SQL queries and database operations.

## Database Tables
- **Books:** Book details, author, genre, price, and stock.
- **Customers:** Customer information and location.
- **Orders:** Order dates, quantities, and total amounts.

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- Aggregate Functions: SUM(), AVG(), COUNT()
- GROUP BY and HAVING
- JOIN operations
- DISTINCT and LIMIT
- Data filtering and analysis

## Tools Used
- MySQL 8.0
- MySQL Workbench
- CSV files for sample data

## Key Analysis
- Identify the most expensive and lowest-stock books.
- Calculate total revenue and book sales by genre.
- Find frequently ordered books.
- Analyse customer orders and spending.

## Files Included
- `Books.csv`
- `Customers.csv`
- `Orders.csv`
- `Project on SQL Only Questions.sql`
- `Project_Questions_ans.sql`

## How to Run
1. Open MySQL Workbench.
2. Execute the database creation and table creation queries.
3. Import the sample CSV data.
4. Run the SQL queries to explore the bookstore data.
